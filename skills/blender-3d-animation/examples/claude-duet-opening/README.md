# 例子：Claude Duet 实机演示 · 15 秒 3D 开头（2026-10-27）

毛毡圆片 Duet 从笔记本屏幕破屏而出，跳上手机沿 7 行消息滚过（逐行点亮），再跳回电脑，在剧本文档上滚下来，最后探出屏幕边缘，屏幕显示标题。

- `brief.md`：当时的需求原文（路径已换成占位）。
- `prep_textures.py`：本期的打码和裁切坐标（通用版见 `scripts/prep_screens.py`）。
- `duet_opening.py`：完整场景脚本，新镜头从这里复制改起。
- 素材和截图不在仓库里（含个人信息）。脚本期望的目录：`<输出目录>/textures/` 下放 `laptop_main.png`、`laptop_script_doc.png`、手机图，`phone_rows.json` 可覆盖手机图和 7 行像素位置。

## 结果

- 1920×1080、30 fps、450 帧；M5 Pro 上 160 spp 全片 64 分钟。
- 受光面取色：#D36940–#E07446（目标 #D0744E），靠按段调反照率补偿。
- 检查时发现并修掉：颜色过亮发黄；屏幕段过亮约 40%；132/238/264 帧主角出画；定格时出 9:16 中间区；桌面和手机屏反光太强；屏幕图标太大。
- 交付时留下的偏差：手机屏是灰色占位（用户同意）；剧本截图只有 2000 px；毛毡绳两端收到圆片边缘内（参考图里伸出），以便滚动时不扎进桌面。

以上是 0.1.0 交付的成片（README 顶部的视频）。

## 0.2.0 的脚本改了什么

- 主角改用 Light Linking 单独打光，删掉按段补偿；检查帧取色 #CA6940–#E2784C。
- 按 `bounds_check.py` 改了 78、120、135–256、362 帧的相机关键点，全片 `BOUNDS OK`。
- 手机段圆片走在远离镜头的一侧，亮行不再被挡。
- full 模式支持断点续渲。

0.2.0 只渲了检查帧，没重渲全片。

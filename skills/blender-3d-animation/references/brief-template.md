# 需求模板

复制后填空，没有的项删掉。例子见 `examples/claude-duet-opening/brief.md`。

```
<一句话：做什么、多长、给哪里用>

项目目录：<绝对路径>；素材在 素材/，输出到 输出/<镜头名>/

素材
- <角色参考图>：主角长什么样
- <屏幕截图 A>：放在哪块屏幕、什么时候出现（按内容挑，不按文件名）
- 缺图时：停下告诉我 / 用中性占位
隐私：哪些要打码；状态栏和地址栏裁掉

主角
- 形状、尺寸感、材质、主色 HEX、暗面色
- 不要的东西（脸、手脚、文字……）
- 运动方式：滚 / 跳 / 落地挤压 / 摇晃

场景
- 桌面、设备摆放、主光方向和色温、轮廓光、景深、机位
- 画面里不能有的东西（其他 Logo、品牌、文字）

镜头表（<BPM>，1 拍 = <帧> 帧）
- 0–60：……
- 60：……（卡拍点的动作）
- ……
- 最后：标题“……”，字体，完整在屏幕内，定格到结尾

规格
- Blender 5，Cycles GPU，<宽>x<高>，<fps>，<帧数>
- 动作留在中间 <区域>，方便以后裁 9:16
- 交付：脚本、.blend、PNG 序列、H.264 MP4，无音频

检查
1. 动画前：屏幕贴图在物体上的正面图 + 接触表（帧号……）
2. <N> 张半分辨率静帧，逐张检查：取色对 HEX、图案朝向、屏幕可读、事件顺序、标题位置、无多余物体
3. 按帧号列问题，修完再渲全片

汇报：取色结果、每项不通过的检查和改动、输出路径
```
